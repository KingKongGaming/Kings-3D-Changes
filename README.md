# Kings-3D-Changes
### This Resourse pack changes some things from 2D to 3D!

The "things" that change:
- Chain
- Rail
- Powered Rail
- Detector Rail
- Activator Rail
- Ladder
- String (Tripwire)
- Piston (Makes it more clear if it is a piston or sticky piston)
- Hoppers (Adds arrows for more clear direction)
- Powder Snow (Makes powder snow more blue)
- Totem of Undying is now a Joint (with animation)
